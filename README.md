# SokoCredit

SokoCredit is a React-based microfinance operations portal for administrators, field agents, loan officers, and customers. It supports customer onboarding, loan workflows, communications, field operations, reporting, and agent activity monitoring.

## Application

The frontend application and its complete setup guide are located in [`sokocredit-frontend`](./sokocredit-frontend/).

For installation, demo accounts, configuration, available modules, testing, and deployment guidance, read the [frontend README](./sokocredit-frontend/README.md).

## Quick start

```bash
cd sokocredit-frontend
npm install
npm run dev
```

## Quality checks

```bash
cd sokocredit-frontend
npm run lint
npm test
npm run build
```
